public class NPCPlugin extends JavaPlugin {

    // Dictionnaire des conversations actives (UUID du joueur ou "debug-session" → session)
    private final Map<UUID, ConversationSession> activeConversations = new HashMap<>();

    @Override
    public void onEnable() {
        // Commandes
        this.getCommand("talk").setExecutor(new TalkCommand(this));
        this.getCommand("stoptalk").setExecutor(new StopTalkCommand(this));
        this.getCommand("startdebug").setExecutor(new StartDebugCommand(this));

        // Listener pour les interactions avec les entitées
        getServer().getPluginManager().registerEvents(new EntityInteractionListener(this), this);

        getLogger().info("NPCDialogue plugin enabled!");
    }

    @Override
    public void onDisable() {
        getLogger().info("NPCDialogue plugin disabled!");
    }


    public Map<UUID, ConversationSession> getActiveConversations() {
        return activeConversations;
    }

    // Récupère une session de conversation existante pour un joueur donné
    public Optional<ConversationSession> getConversation(UUID playerId) {
        if (activeConversations.containsKey(playerId)) {
            return Optional.of(activeConversations.get(playerId));
        }
        return Optional.empty();
    }

    // Crée une nouvelle session de conversation pour un joueur donné, si elle n'existe pas déjà
    public void newConversation(UUID playerId, ConversationSession session) {
        activeConversations.put(playerId, session);
    }



    // TEMPORAIRE
    // Pour le débug

    private boolean debugMode = false;

    public boolean isDebugMode() {
        return debugMode;
    }

    public void setDebugMode(boolean debugMode) {
        this.debugMode = debugMode;
    }
}

-TalkCommand.java :
public class TalkCommand implements CommandExecutor {

    private final NPCPlugin plugin;

    public TalkCommand(NPCPlugin plugin) {
        this.plugin = plugin;
    }

    @Override
    public boolean onCommand(CommandSender sender, Command command, String label, String[] args) {
        // Récupère l'uuid du joueur
        final UUID sessionId = (sender instanceof Player)
                ? ((Player) sender).getUniqueId()
                : UUID.nameUUIDFromBytes("debug-session".getBytes(StandardCharsets.UTF_8));

        // Vérifie si le joueur à une conversation en cours ou non
        var conversations = plugin.getActiveConversations();
        if (!conversations.containsKey(sessionId)) {
            sender.sendMessage(ChatColor.RED + "You're not talking to any NPC right now. Right-click an NPC to start.");
            return true;
        }

        // Vérifie le format de la commande
        if (args.length == 0) {
            sender.sendMessage(ChatColor.RED + "Usage: /talk <message>");
            return true;
        }

        // Parse le message et l'ajoute à la session
        String userMessage = String.join(" ", args);
        ConversationSession session = conversations.get(sessionId);
        session.addMessage("player", userMessage);

        // Pareil avec la réponse du npc
        String response = OllamaAPI.getResponseFromOllama(session, plugin.getLogger());
        session.addMessage("npc", response);

        // Affiche le résultat du message
        //TODO : à formater
        if (sender instanceof Player player) {
            player.sendMessage(ChatColor.GOLD + session.getNpcName() + ChatColor.WHITE + ": " + response);
        } else {
            // S'affiche dans la console si en mode débug
            plugin.getLogger().info("[DEBUG][" + session.getNpcName() + "] " + response);
        }

        return true;
    }
}

                ? ((Player) sender).getUniqueId()
                : UUID.nameUUIDFromBytes("debug-session".getBytes(StandardCharsets.UTF_8));

        if (plugin.getActiveConversations().remove(sessionId) != null) {
            sender.sendMessage(ChatColor.GRAY + "You ended the conversation.");
        } else {
            sender.sendMessage(ChatColor.RED + "You're not talking to any NPC.");
        }

        return true;
    }

-EntityInteractionListener.java:
public class EntityInteractionListener implements Listener {

    private final NPCPlugin plugin;

    public EntityInteractionListener(NPCPlugin plugin) {
        this.plugin = plugin;
    }

    @EventHandler
    public void onEntityInteract(PlayerInteractEntityEvent event) {
        Player player = event.getPlayer();
        Entity entity = event.getRightClicked();


        //TODO : à supprimer
        if (entity.getCustomName() == null) {
            player.sendMessage(ChatColor.YELLOW + "This entity has no name.");
            return;
        }

        // Récupère le nom du npc, l'uid du joueur et les conversations du plugin
        String npcName = entity.getCustomName();
        UUID playerId = player.getUniqueId();
        Optional<ConversationSession> optional = plugin.getConversation(playerId);

        ConversationSession session;

        if (optional.isPresent()) {
            session = optional.get();
            // Si le joueur a déjà une session en cours
            if (session.getNpcName().equals(npcName)) {
                // Soit c'est le même NPC
                player.sendMessage(ChatColor.GRAY + "* You are already talking to " + ChatColor.GOLD + npcName);
            } else {
                // Soit c'est un nouveau NPC
                player.sendMessage(ChatColor.GRAY + "* You switched to talk to " + ChatColor.GOLD + npcName);
                session = new ConversationSession(npcName);
                session.addMessage("system", getSystemPrompt(npcName));
                plugin.newConversation(playerId, session);
            }
        } else {
            // Sinon on en crée une nouvelle
            player.sendMessage(ChatColor.GRAY + "* You start talking to " + ChatColor.GOLD + npcName);
            session = new ConversationSession(npcName);
            session.addMessage("system", getSystemPrompt(npcName));
            plugin.newConversation(playerId, session);
        }

        // Génère la réponse du NPC via l'API
        String response = OllamaAPI.getResponseFromOllama(session, plugin.getLogger());
        session.addMessage("npc", response);

        // Affiche la réponse au joueur
        player.sendMessage(ChatColor.GOLD + npcName + ChatColor.WHITE + ": " + response);
    }

    private String getSystemPrompt(String npcName) {
        return "You are a medieval NPC named " + npcName + ". The player wants to talk to you. Introduce yourself and ask a question.";
    }
}

public class ConversationSession {

    public List<Message> getMessages() {

    public String getNpcName() {

Dans la classe OllamaAPI, il doit y avoir toutes les fonctions utiles à la communication avec l'API d'Ollama.
Les informations sur le fonctionnement de l'API sont disponibles dans la documentation ici https://github.com/ollama/ollama/blob/main/docs/api.md.


Au vu de l'architecture actuelle de mon plugin, je pense avoir besoin de communiquer avec les endpoint suivants via deux fonctions:
- POST /api/generate : lors de l'initialisation d'une discussion avec un NPC
On prend en entrée un texte qui décrit au NPC "qui" il est et son rôle. On retournera la réponse donnée par le NPC.
- POST /api/chat : On prend en entrée une ConversationSession. Cette ConversationSession contient entre autres la liste des messages à fournir à l'API qui va lui servir de contexte. On retournera la réponse donnée par le NPC.


Note : Les messages peuvent avoir les rôles suivants "system, user, assistant ou tool", pour le message d'initialisation il doit être de type système. Pour un chat, on aura donc une liste de messages de la forme (message système, message NPC, message user, message NPC, ... ,  message joueur).
Aussi, en communiquant avec l'API il faudra utiliser le paramètres "format" pour donner un JSON schema et modifier le format de la sortie et ne garder que les informations essentielles. La sortie sera ensuite traitée pour extraire la réponse du NPC et ne renvoyer qu'une seule String dans la fonction.
